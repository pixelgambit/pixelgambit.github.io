# Pixel Gambit

The Pixel Gambit website, served by GitHub Pages at https://pixelgambit.github.io/.

- `index.html`: home page listing everything looking for testers
- `fastline/`, `monster-bound/`, `mythos/`, `pixel-sevens/`: one page per app or game
- `fastline/privacy/`: Fastline privacy policy (use this URL in the Play listing)

Every page points testers at one Google Group: https://groups.google.com/g/pixelgambit-testers

Plain HTML and CSS, no build step.
